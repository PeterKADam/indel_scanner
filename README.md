# Indel Scanner

A parallel pipeline for scanning Pacbio Hifi reads alignments against a denovo assembly reference FASTA, extracting
indel candidates, applying STR/homopolymer filters, and writing per-type mutation
frequency reports. The main entry point is `python -m indel_scanner.main`, which is
wrapped by `./run.sh`

## Installation

This repo includes a full conda environment intended to be run on linux HPC cluters. Create it from `environment.yaml`:

```bash
conda env create -f environment.yaml
conda activate indel_scanner
```

Notes:
- You need indexed BAM (`.bam` + `.bai`) and indexed FASTA (`.fa` + `.fai`).
- STR results must exist for each contig (generated by RPTRF https://github.com/rezabehboudi/RPTRF ).

## Running

### Quick start (use `run.sh`)

Edit the paths in `run.sh` and run:

```bash
./run.sh
```

This executes:

```bash
python -m indel_scanner.main \
  --bam "/path/to/sample.bam" \
  --fasta "/path/to/reference.fa" \
  --strdir "/path/to/repeatregions" \
  --output "/path/to/results" \
  --config "config.yaml"
```

### Outputs

Outputs are written under:

```
{output}/{sample_name}/{timestamp}/
```

Key files:
- `settings_used.yaml` (full resolved config + inputs)
- `processed/final_passed_indels.tsv`(single TSV with every indel candidate)
- `per_type_mutation_frequency.tsv`
- `logs/`

## Configuration

Configuration is read from `config.yaml` and merged with CLI args. Sections:

- `scanner`: scan parameters and thresholds
- `processor`: filters and output naming
- `reporting`: report filenames
- `io`: read/write buffer sizes
- `pipeline`: parallel behavior, sampling, STR/complexity options

A default config can be found in configs/default_config.yaml with annotated configuration options

## Project structure

```
indel_scanner/
  indel_scanner/
    main.py              # CLI entry point
    configurator.py      # CLI args + config resolution
    parallel.py          # multiprocessing pipeline
    scanner.py           # contig scanning and candidate extraction
    filters.py           # STR/homopolymer/quality filters
    STR_Classifier.py    # STR classification from RPTRF output
    homopolymer_classifier.py
    IO.py                # TSV write/aggregate helpers
    reporting.py         # per-type mutation frequency report
    indel.py             # Indel record types
  run.sh                 # wrapper for main pipeline
  configs/default_config.yaml
  config.yaml            #  pipeline configuration
  test/                  # unit tests
```
